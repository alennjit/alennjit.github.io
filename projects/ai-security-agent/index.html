AI Security Agent

Catch confidential data before it is pasted into an AI chatbot.

In development · 2026

PythonmitmproxyFastAPISQLAlchemypytest

Source on GitHub

Overview

Network-level data-loss prevention for AI usage. A TLS-inspecting proxy spots prompts headed to ChatGPT, Claude, Gemini and other AI services, scans them for secrets, credentials and personal data, and reports findings to a SIEM-style backend for administrators.

Screenshots

The problem

Employees paste source code, API keys and customer data into AI tools every day, and browser-extension monitors miss API calls and non-browser apps entirely. A network control sees all of it, and mirrors the SSL-inspection model organizations already run on their firewalls.

How it works

A mitmproxy add-on matches traffic against a registry of known AI services, then uses per-provider extractors to pull out only the text the user typed — not system prompts or earlier turns.

A DLP engine scores that text on a 1 to 10 scale. It detects AWS keys, GitHub and Slack tokens, private key blocks, JWTs, SSNs, Luhn-validated card numbers and confidential-marker keywords.

The detector is redaction-first: it never stores or returns the raw match, only a masked snippet, so the monitoring tool cannot become a new store of secrets. The consent model is disclosure through acceptable-use policy with a silent runtime, and it is documented in the repo.

Highlights

  • Redaction by design: findings carry the rule, category, weight and a masked snippet — never the secret itself.
  • Luhn validation removes most false positives on credit-card-shaped numbers.
  • Extractors for the OpenAI, Anthropic and Gemini request formats, plus a best-effort web-UI parser.
  • 29 automated tests across the DLP engine, extractors and the FastAPI ingestion backend.

What's next

  • Validate the proxy add-on against real captured traffic for each provider.
  • Build the admin dashboard.
  • Root CA and PAC/GPO deployment tooling, with certificate-pinning checks.
  • Multi-tenant separation and per-client keyword lists.
